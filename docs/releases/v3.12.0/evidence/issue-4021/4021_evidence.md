## What was NOT delivered (honest gap)

1. **End-to-end scrape test against a running sqlrustgo MySQL server** —
   the unit tests cover the renderer/helper, not the live HTTP binding
   (port wiring, scrape handshake). A live `/metrics` curl test would
   require starting a sqlrustgo server with `--metrics-port N` and
   `curl -s http://127.0.0.1:N/metrics | grep sqlrustgo_queries_total`.
   This end-to-end verification is not captured in this evidence pack.

2. **No `evidence/issue-4021/live-scrape/` directory** — would be
   generated by the missing live-scrape test. The unit tests cover
   the contract; the live binding is a separate concern.
