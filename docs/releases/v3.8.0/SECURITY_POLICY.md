# SQLRustGo 安全策略

> **版本**: v3.8.0
> **发布日期**: 2026-06-04

---

## 当前安全状态

| 组件 | 状态 | 说明 |
|------|------|------|
| 传输加密 | ⚠️ | rustls 代码存在，TLS 配置未完成 |
| 用户认证 | ⚠️ | 简单密码验证，SHA1 可用 |
| 访问控制 | ⚠️ | 仅支持单用户(root)模式 |
| SQL 注入防护 | ✅ | 参数化查询完全支持 |

---

## 已知安全限制

| ID | 问题 | 缓解措施 |
|----|------|---------|
| SEC-01 | 无 TLS/SSL | 仅在可信网络使用 |
| SEC-02 | 密码明文传输 | 部署在内网环境 |
| SEC-03 | 无 RBAC | 限制数据库用户权限 |

---

## 部署安全建议

```bash
# 仅监听本地
sqlrustgo-mysql-server serve --host 127.0.0.1 --port 3306

# 文件权限
chmod 700 /var/lib/sqlrustgo
chown sqlrustgo:sqlrustgo /var/lib/sqlrustgo
```
