## 二、五项原则审查标准

| 原则 | 要求 | 适用于 |
|------|------|--------|
| **P1: 测试同步设计** | PR 必须包含测试代码，且与功能代码同步提交 | 所有功能 PR |
| **P2: 验证正确性** | 测试断言必须验证具体值/状态，不只是"能跑通" | 所有测试 |
| **P3: WAL必须有replay测试** | 涉及 WAL/Storage/Recovery 的 PR 必须有专门的 replay 测试 | PR-830, PR-840, PR-850 |
| **P4: 覆盖率量化** | 必须提供覆盖率数据，新增代码覆盖率 ≥80% | 所有 PR |
| **P5: PR审核包含测试审核** | Code review 必须包含独立的测试质量维度 | 所有 PR |
