## How to regenerate

```bash
# Install (one-time)
cargo install cargo-llvm-cov

# Run baseline generation (workspace-wide, 20-40 min)
bash scripts/coverage/llvm_cov_baseline.sh

# Custom target (e.g. RC: 70%)
CRATE_TARGET=70 bash scripts/coverage/llvm_cov_baseline.sh
```

The script writes one `<crate>-lib.json` per workspace member into this directory and a top-level `summary.json` aggregating `percent_covered` across crates. Exits non-zero if any crate is below target — use this in CI to hard-fail on coverage regressions.
