## 1. 功能边界

### 1.1 输入（中文 GMP 记录）
- 批次记录（Batch Record）: 原料/工序/检验/放行
- 偏差调查报告（Deviation Report）: 偏差描述 + 根因 + CAPA
- 设备运行记录（Equipment Log）: 运行参数 + 维护记录

### 1.2 输出（英文合规报告）
- **FDA 21 CFR Part 11** 格式: 批记录总结 / 偏差分析 / 放行建议
- **EMA Annex 11** 格式: 合规声明 / 审计追踪 / 电子签名记录

### 1.3 核心 GMP 术语翻译要求
- GMP 关键术语: 100% 准确（batch, deviation, CAPA, audit trail 等）
- 通用内容: ≥ 95% 准确率

## 2. API 设计

### 端点
```
POST /api/v1/gmp/report/translate
```

### 请求结构
```rust
#[derive(Deserialize)]
pub struct TranslateRequest {
    /// 中文 GMP 记录内容（Markdown 或 JSON）
    pub input: String,
    /// 报告类型: batch_record | deviation_report | equipment_log
    pub report_type: ReportType,
    /// 合规标准: fda_21cfr11 | ema_annex11
    pub standard: ComplianceStandard,
}

pub enum ReportType {
    BatchRecord,
    DeviationReport,
    EquipmentLog,
}

pub enum ComplianceStandard {
    Fda21Cfr11,
    EmaAnnex11,
}
```

### 响应结构
```rust
#[derive(Serialize)]
pub struct TranslateResponse {
    /// 英文合规报告（Markdown）
    pub output: String,
    /// 术语对照（关键 GMP 术语）
    pub term_translations: Vec<TermTranslation>,
    /// 翻译准确率评分（0.0~1.0）
    pub accuracy_score: f64,
    /// 审计链 ID
    pub audit_trail_id: String,
}
```

## 3. 核心翻译逻辑

### 3.1 三步流程
```
输入文本 → [术语预处理] → [LLM 翻译] → [术语校验] → 英文报告
```

1. **术语预处理**: 本地字典替换 GMP 术语（如"偏差"→"Deviation"）
2. **LLM 翻译**: qwen2.5:7b via Ollama（prompt 含标准格式要求）
3. **术语校验**: 验证输出中关键 GMP 术语翻译正确，计算准确率

### 3.2 LLM Prompt 模板
```
你是一个 GMP 合规报告翻译专家。请将以下中文 GMP 记录翻译成英文。
遵循 {standard} 格式要求。

关键术语必须准确翻译:
- 批次 → Batch
- 放行 → Release / Lot Release
- 偏差 → Deviation / Out-of-Specification (OOS)
- 偏差调查 → Deviation Investigation
- 根因分析 → Root Cause Analysis (RCA)
- CAPA → Corrective and Preventive Action (CAPA)
- 原料 → Raw Material / Active Pharmaceutical Ingredient (API)
- 审计追踪 → Audit Trail
- 规程 → Standard Operating Procedure (SOP)

[输入内容]

输出格式:
{section_headers}
- 每段以英文小标题开头
- 关键术语首次出现附原文
- 保持技术准确性
```

## 9. 风险与缓解

| 风险 | 影响 | 缓解 |
|------|------|------|
| LLM 翻译 GMP 术语错误 | 合规风险 | 本地字典预处理 + 后处理校验，双重保护 |
| Ollama 未启动 | 功能不可用 | API 返回清晰错误，fallback 到 OpenAI API |
| 专业术语歧义 | "放行" 在不同语境不同 | 术语字典含语境标识，prompt 强调场景 |
