## 一、概述

本文档追踪 SQLRustGo v3.5.0 的 OO (Object-Oriented) 文档进展。v3.5.0 定位为 **AI Native GMP Platform — Alpha**，核心目标：

1. AI Agent Layer（偏差调查、合规判断、报表生成、设备预测）
2. GMP Retrieval v3（BM25 + Vector + Graph 三路融合）
