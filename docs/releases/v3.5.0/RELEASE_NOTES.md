## 版本概述

v3.5.0 是 SQLRustGo 的第四个 GA 版本，以 AI Native GMP Platform 为核心定位，将 AI 能力深度嵌入 GMP 全流程——偏差调查、根因分析、合规判断、设备预测性维护——实现 "AI-native" 而非 "AI-augmented"。

---

## 核心变更

### AI Agent Layer（P0）— `gmp-api`

- **跨语言合规报告**（#1411）：GMP 中文记录 → FDA 21 CFR Part 11 / EMA Annex 11 英文报告，支持本地术语预处理 + Ollama LLM 翻译
- **AI 偏差调查助手**（#1360）：自然语言查询审计链，返回引用证据
- **LLM 合规判断引擎**（#1362）：输入批次数据 + 规则，输出放行建议 + 理由
- **本地 LLM 推理**（#1364）：Ollama/bge-m3 本地推理，延迟 < 2s
- **AI 流式输出 SSE**（#1365）：Server-Sent Events 实时输出 AI 推理过程

### P1 - 扩展 AI 能力

- **设备预测 Agent**（#1366）：时序数据 + 模型预测设备故障，提前 24h 预警
- **报表生成 Agent**（#1367）：一句话生成批次/合规/偏差报表（Markdown/PDF）
- **审计链 AI 摘要**（#1368）：长审计链自动摘要为 200 字摘要
- **规则自动推荐**（#1369）：基于历史偏差数据推荐新规则

### P2 - 增强功能

- **多模态输入**（#1409）：上传现场图片 + 文字描述，AI 综合判断
- **语音批次录入**（#1410）：语音转文字，录入批次步骤
- **AI 合规培训助手**（#1412）：新员工 AI 培训，GMP 规则问答
